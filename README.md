## 🌻 Sobre Mim 🌻

Olá, eu sou o Fernando Nillsson Cidade! Desenvolvedor de software autodidata com sólida prática em C++ (C++17/C++20), Rust (Edições 2021/2024), C e Python (3.10+), dedicado ao estudo e implementação de arquitetura de sistemas nativos de altíssima performance, design de código limpo e seguro em memória, estruturas de dados e algoritmos avançados, paralelismo multi-core e vetorização SIMD, cibersegurança e auditoria forense de sistemas de arquivos, processamento massivo de logs em tempo real, simulação estrutural, eólica, geotécnica e de tecnologia do concreto (normas ABNT NBR), engenharia econômica, ciência de dados, compressão de dados, acessibilidade cognitiva para neurodivergentes e ferramentas de produtividade — aliando Qt6, egui/WGPU, Win32 API e bancos de dados relacionais locais com soberania total de dados (100% offline e zero telemetria).
