📜 Descrição Completa da Habilidade Complete Skill Description

Programação de sistemas próxima ao hardware (arquitetura x86-64), mapeamento de arquivos diretamente no espaço de endereçamento virtual do kernel (Memory-Mapped Files via CreateFileMappingW e MapViewOfFile para abertura instantânea de arquivos de múltiplos gigabytes com RAM constante), vetorização de CPU com instruções SIMD de 256 e 128 bits (intrínsecos AVX2, AVX, SSE4.2 e SSE2 como _mm256_cmpeq_epi8 e _mm256_movemask_epi8 com fallback escalar dinâmico atingindo vazão superior a 3,0 GB/s), I/O assíncrono de kernel com buffers alinhados (ReadDirectoryChangesW e FindFirstFileExW com latência sub-milissegundo), streaming em blocos de memória limitada (memory-bounded chunks de 1 a 4 MB), temporização monotônica de alta precisão (std::chrono e QElapsedTimer), aritmética de ponto flutuante IEEE 754 de dupla precisão (64 bits) e integração nativa com subsistemas Win32 (Advapi32, Secur32, Netapi32, ShellExecuteW, DWM API e SAPI5/OneCore).

Hardware-close systems programming (x86-64 architecture), direct virtual address space file mapping (Memory-Mapped Files via CreateFileMappingW and MapViewOfFile for instant multi-gigabyte file opening with constant RAM usage), CPU vectorization with 256-bit and 128-bit SIMD instructions (AVX2, AVX, SSE4.2, and SSE2 intrinsics such as _mm256_cmpeq_epi8 and _mm256_movemask_epi8 with dynamic scalar fallback exceeding 3.0 GB/s throughput), asynchronous kernel I/O with aligned completion buffers (ReadDirectoryChangesW and FindFirstFileExW with sub-millisecond dispatch), memory-bounded stream chunk processing (1 to 4 MB chunks), high-precision monotonic timing (std::chrono and QElapsedTimer), 64-bit IEEE 754 double-precision floating-point arithmetic, and native Win32 subsystem integration (Advapi32, Secur32, Netapi32, ShellExecuteW, DWM API, and SAPI5/OneCore).

Vetorização SIMD AVX2 & SSE4.2 (256/128 bits)AVX2 & SSE4.2 SIMD Vectorization (256/128-bit)

_mm256_cmpeq_epi8 • >3.0 GB/s

Processamento simultâneo de 32 bytes por ciclo de instrução utilizando registradores YMM de 256 bits (intrínsecos AVX2) e XMM de 128 bits (SSE4.2/SSE2) para indexação de quebras de linha e varredura de padrões em logs massivos a mais de 3,0 GB/s.

Simultaneous processing of 32 bytes per instruction cycle using 256-bit YMM registers (AVX2 intrinsics) and 128-bit XMM registers (SSE4.2/SSE2) for newline indexing and pattern scanning in massive logs at over 3.0 GB/s.

Mapeamento em Memória Virtual (Memory-Mapped I/O)Virtual Memory Mapping (Memory-Mapped I/O)

CreateFileMappingW • MapViewOfFile

Abertura instantânea de arquivos de 10 GB+ mapeando páginas diretamente do cache de sistema do kernel para o espaço de endereçamento virtual do processo, mantendo consumo de memória RAM constante (~35 MB) independentemente do tamanho do arquivo.

Instant opening of 10 GB+ files by mapping pages directly from the kernel system cache into the process virtual address space, maintaining a constant RAM footprint (~35 MB) regardless of file size.

I/O Assíncrono de Kernel & StreamingAsynchronous Kernel I/O & Streaming

Captura de eventos do sistema de arquivos NTFS diretamente do kernel com latência sub-milissegundo e enumeração otimizada de diretórios (FindFirstFileExW com FindExInfoBasic), aliada ao processamento de streams criptográficos em blocos de 1 a 4 MB.

Direct NTFS file system event capture from the kernel with sub-millisecond latency and optimized directory enumeration (FindFirstFileExW with FindExInfoBasic), paired with cryptographic stream processing in 1 to 4 MB chunks.
