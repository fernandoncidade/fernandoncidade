⚙️ Arquitetura de Software & Engenharia Software Architecture & Engineering

Engenharia C++ de Alto Desempenho High-Performance C++ Engineering

Construído em C++17 e interface nativa em Qt 6, o Linceu Lighthouse foi desenvolvido com foco em consumo mínimo de recursos computacionais, baixa latência de I/O e robustez multithread. Ele utiliza threads desacopladas de captura de eventos e escrita em lote no banco de dados para evitar gargalos na interface gráfica.

Built in C++17 with native Qt 6 presentation, Linceu Lighthouse was engineered with a strict focus on minimal resource consumption, low I/O latency, and multi-threaded resilience. It isolates kernel event capture from database persistence via lock-free or ring-buffer queues to eliminate UI freezes.

Subssistema de Notificação Win32 Win32 Notification Subsystem ReadDirectoryChangesW

Utiliza buffers alinhados e I/O completion assíncrono para receber notificações diretas do driver NTFS/FAT32 com latência inferior a 1 ms, tratando renomeações complexas e transientes.

Leverages aligned buffers and asynchronous I/O completion to receive direct notification packets from NTFS/FAT32 drivers with sub-millisecond dispatch.

Pipeline Criptográfico Multi-Thread Multi-Threaded Hashing Pipeline QCryptographicHash / OpenSSL

O hashing de arquivos é executado em um thread pool de background dedicado, evitando qualquer degradação da taxa de quadros (60 FPS) da interface visual mesmo sob rajadas de I/O de milhares de arquivos.

File cryptographic checksums run in a dedicated background worker pool, guaranteeing a stable 60 FPS UI responsiveness even during heavy bursts of disk I/O.

Camada de Persistência Transacional Transactional Persistence Layer SQLite3 + WAL Mode

Configurado com PRAGMA journal_mode=WAL e synchronous=NORMAL, viabilizando leituras concorrentes ultrarrápidas sem bloquear inserções simultâneas de eventos.

Configured with PRAGMA journal_mode=WAL and synchronous=NORMAL, unlocking concurrent lock-free reads while high-frequency inserts stream continuously.
