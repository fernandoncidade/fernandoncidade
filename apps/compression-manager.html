Proteção Blindada Contra Falhas de Disco e Ransomware Armored Defense Against Hardware Failure & Ransomware

O COMPRESSION MANAGER é uma central completa de cópias de segurança (backup) e arquivamento para profissionais e empresas. Ele permite criar rotinas automatizadas que compactam pastas estratégicas em formatos ultra-eficientes (como LZMA e 7z) e protegem o conteúdo com criptografia militar AES-256 antes de salvá-lo em discos externos, pendrives ou locais de rede.

COMPRESSION MANAGER is a comprehensive backup automation and archiving workstation built for professionals and businesses. It enables automated backup recipes that compress mission-critical folders into ultra-dense formats (such as LZMA and 7z) and shield data with military-grade AES-256 encryption before writing to external storage or network shares.

Encrypted Archives Only You Can Unlock
Mesmo que um dispositivo de backup seja perdido ou roubado, a criptografia simétrica AES-256 impede qualquer acesso não autorizado aos seus documentos, bancos de dados e fotos pessoais.
Even if an external backup drive or USB key is misplaced, AES-256 encryption guarantees that your confidential documents, source code, and databases remain completely inaccessible to unauthorized parties.

Smart Exclusion Rules

Evite desperdiçar espaço ignorando automaticamente pastas temporárias como node_modules, .git, __pycache__ e lixeiras.

Save disk space and hours of time by filtering out transient artifacts such as node_modules, .git, __pycache__, and cache folders.

Verificação de Integridade CRC32/SHA-256

Integrity Verification Checksums

Após a compactação, o sistema verifica automaticamente a integridade dos blocos gerados para certificar que nenhum arquivo foi corrompido.

Automatic post-compression checksum validation verifies that archived blocks are completely sound and ready for restoration.

⚙️ Engenharia Python & Arquitetura Concorrente Python Engineering & Concurrent Pipeline

Processamento Paralelo e Pipelines Não-Bloqueantes Parallel Multi-Threaded Compression Pipelines

Desenvolvido com Python 3.10+ e PySide6, o COMPRESSION MANAGER adota uma arquitetura orientada a eventos com trabalhadores concorrentes via QThread e pools de subprocessos, garantindo fluidez total na interface mesmo ao compactar centenas de gigabytes.

Engineered using Python 3.10+ and PySide6, COMPRESSION MANAGER implements an asynchronous event-driven design powered by QThread workers and native multi-core archiving binaries, ensuring uninterrupted UI responsiveness during multi-gigabyte compression passes.

Módulo Criptográfico de Alto Padrão Standards-Compliant Cryptography pycryptodome / AES-256-CBC / GCM

Geração de chaves robustas derivadas via PBKDF2 com salt aleatório e derivação de hash SHA-256 para prevenir ataques de dicionário e rainbow tables.

Cryptographic keys are derived using PBKDF2 with high iteration counts and cryptographic random salts to defeat dictionary attacks.

Tratamento de I/O por Streaming Stream-Based Buffer Chunks Memory-Bounded File Streams

Os arquivos são compactados e criptografados em fluxos segmentados (chunks de 1 a 4 MB), impedindo que o uso de memória RAM escale proporcionalmente ao tamanho dos arquivos compactados.

I/O operations stream through fixed 1–4 MB memory chunk buffers, keeping working RAM strictly bounded regardless of whether a 50 MB or 100 GB volume is processed.
